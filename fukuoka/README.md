# 🍜 벳푸·후쿠오카 가족여행 (2026.11.29 일 – 12.4 금, 5박6일)

오이타공항 입국 → 벳푸 온천 3박(스기노이 2 + 하나벳푸 1) → 특급 소닉 → 하카타 2박(미야코 호텔) → 후쿠오카공항 출국.
**현재 상태: 1차안.** 항공·숙소·소닉은 예약 내용 그대로, 관광지는 예약 불필요한 곳 위주. 새로 예약·결제한 것은 없음.

## 🍽️ 맛집은 동선에 넣지 않는다
사용자가 구글 지도 목록 '26년 일본여행'에 즐겨찾기한 12곳을 **후보로만** 제시하고 당일에 고른다. 일정표 타임라인에는 식사 자리표시("맛집 후보에서 고르기")만 있다. 호텔 조식·스기노이 석식(11/29~30)·하나벳푸 석식(12/1)은 숙박 포함 범위가 기준.
후보를 바꾸려면 데이터 원본 한 곳(`locations.js`의 `pick_*` 항목)과 일정표의 후보 카드를 함께 고친다.

## 🛍️ 쇼핑목록 추가
화면 입력칸에서 적은 항목과 체크 표시는 taean-camping과 같은 Firebase Realtime Database(`…/checklist/fukuoka`, REST 폴링 5초)에 저장돼 **가족 모두에게 공유**된다(✕ 삭제도 공유). 오프라인 등으로 못 올린 항목은 그 기기에 임시로 두었다가 연결되면 자동 업로드. 사진·가격이 필요한 항목은 `shopping.json`의 `items`에 `{ "id": "…", "name": "…", "photo": "shopping-photos/…jpg", … }`로 추가(`name`만 필수). 사진은 올리기 전에 위치·촬영정보를 지우고 가로 820px 안팎으로 줄인다.
※ DB 보안 규칙에서 `checklist` 경로(하위 `fukuoka` 포함)의 읽기·쓰기가 허용돼 있어야 한다(막혀 있으면 화면에 "연결 안 됨" 표시).

## 🗺️ 구글 내 지도(My Maps)로 가져오기
※ 이미 만들어 공유함: https://www.google.com/maps/d/viewer?mid=15WOosCb-NuJpVjpzObgiSXqQoXHo4g8 (일정표·지도 페이지의 「📌 내 지도」 버튼). 일정이 바뀌면 이 지도의 항목도 함께 고쳐야 한다.
1. https://www.google.com/mymaps → **새 지도 만들기** → **가져오기**에서 `fukuoka_google_mymaps.csv` 업로드
2. 위치 열은 **Search**(장소명 검색) 또는 Latitude/Longitude 중 선택, 마커 제목은 **Name**
3. "스타일 지정 기준"을 **Day**로 하면 날짜별로 색이 나뉜다. 구글 지도 앱에서 "저장됨 → 지도"로 볼 수 있다.
※ 좌표는 OSM 조회값이고 일부는 근사값이라 Search 열 기준을 권장. 가져오기는 아직 실제로 해 보지 않았다.
